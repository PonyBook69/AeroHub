# AeroHub
A simple shortcut Hub for your desktop.

Made by someone getting back into programming — this is my first project back.

## How to use
1. When you launch AeroHub, it will appear in the Windows system tray (bottom right corner)
2. Click the tray icon to open the Hub
3. Drag and drop shortcuts or files into the Hub to add them
4. **Left click** any item to open it
5. **Right click** any item to remove it from the Hub
6. Use the minimize or close buttons to hide the Hub

## Known Issues (BetaV2)
- Visual glitch when resizing the window — the rounded corners may flicker briefly, 
  but the window will stay at the size you set.
